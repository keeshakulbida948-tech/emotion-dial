# 方法：情绪方向怎么找、怎么读、怎么拨

本项目只做三件事，全部**不训练、不改权重**，只在残差流上做线性操作。

## 1. 找方向（extract）

对每个情绪 `E`：

1. 把系统提示写成「你此刻感到 E」（`EMOTION_PROMPTS`）。
2. 用同一批中性用户话（`DEFAULT_PROBES`）各跑一次，取目标层**末位 token** 的残差流激活。
3. 与「中性系统提示」下的激活作差，得到原始方向向量 `v_E`（不归一化）。

之所以用「同一批用户话 + 只换系统提示」，是为了把「用户内容带来的分量」消掉，
留下的主要是情绪带来的偏移。方向集合 `{v_E}` 可保存为 `.pt` 复用（`save_vectors` / `load_vectors`）。

> 残差流的基准范数 `||h||` 会一并算出（`ref_norm`）。`alpha=1` 表示注入「一整份情绪差量」，
> 因此 alpha 是相对于该模型自身激活尺度的，跨模型不能直接比较绝对值。

## 2. 注入（steer）

在目标层的 module 上挂一个 forward hook：每次前向都把

```
h ← h + Σ_i  alpha_i · v_i
```

加到残差流上。`alpha` 可以在两次生成之间随时改（`dial.set(happy=1.0)`），
甚至逐 token 改。`alpha` 为负即「朝相反方向推」。

经验（见 `FINDINGS.md`）：**中层（约总层数的 50%~66%）注入效果最好**；
注得太深（如 32 层模型的第 30 层）且 alpha 偏大时，容易复读/崩坏。

## 3. 读方向：逐情绪定位（localize）

问题：每个情绪「自己」最亮的层在哪？

单一模板会失败——用同一个句框测很多情绪时，差异会被**模板共享分量**和**词嵌入**主导，
自洽度假峰全挤在 L0/L1。所以本工具用**自然场景**：每个情绪 6 句互不相同的生活场景。

对每层 `l`：

- 每句的 diff = 该句激活 − 中性质心（`NEUTRAL_SCENES` 的均值）；再减掉「所有情绪共有成分」。
- **自洽度 rel**：该情绪的 6 句随机对半 3+3，算两组均值的 cosine，多次平均。
- **专属度 uniq**：该情绪方向离「其他任一情绪方向」最近的距离（1 − max 相似度）。
- **定位层 L\*** = `argmax(rel × uniq)`。

输出两张热力图（行=情绪，列=层）：左=联合分，右=专属度，白圈标出峰值层。

## 4. 读方向：逐 token 监测（monitor）

生成过程中，逐 token 看内部「情绪波动」：

1. 取若干情绪的质心方向（`质心 − 中性质心`）做 SVD，取前 3 个正交主成分当「情绪子空间」。
   PC1 通常是**效价轴**（负面 ↔ 正面）。
2. 生成时在目标层 hook，逐 token 拿残差 `h`，算 `d = h − 中性质心`。
3. 指标：
   - **波动 Δ** = `||h_t − h_{t-1}|| / ||h||`（相邻步内部跳变）
   - **PC 投影** = `d · PC_k / ||h||`（落在情绪轴上的位置）
   - **情绪活跃度** = `||d 在子空间上的分量|| / ||d||`（0=纯中性叙述，越大=越被情绪占据）

输出三联曲线图，每行一个提问。

## 局限

- 方向是**线性近似**：只捕捉残差流里的一阶方向，非线性/分布式表示会被漏掉。
- 4bit 量化、模板共享分量会让某些度量（如参与度 PR）明显偏低，但定性结论稳定。
- 「定位层」依赖所选场景；换一批场景数值会动，但**主带位置**通常稳。
- 本项目是**可解释性/行为研究工具**，不是安全护栏，也不是越狱工具。请遵守所用模型的许可与使用条款。
